# گالری فرش آروَن | Arvan Carpet Gallery

وب‌سایت معرفی گالری و پنل مدیریت داخلی.

## فایل‌ها
- `public/index.html` — نسخه عمومی وب‌سایت که GitHub Pages منتشر می‌کند.
- `index.html` — نسخه منبع صفحه اصلی.
- `admin.html` — پنل اولیه مدیریت موجودی، فروش، چک‌ها، هزینه‌ها و سهم شرکا؛ در خروجی عمومی Pages قرار نمی‌گیرد.
- `.github/workflows/pages.yml` — انتشار خودکار پوشه `public` با GitHub Actions.

## انتشار
در مخزن GitHub از مسیر **Settings → Pages**، منبع انتشار را روی **GitHub Actions** قرار دهید (اگر هنوز تنظیم نشده است). سپس در زبانه **Actions** اجرای workflow با نام **Deploy Arvan website to GitHub Pages** را بررسی کنید. پس از موفقیت اجرا، نشانی Pages در جزئیات workflow و بخش Pages نمایش داده می‌شود.

## نکات مهم پنل مدیریت
پنل فعلی یک نسخه اولیه محلی است و داده‌ها را در حافظه مرورگر همان دستگاه ذخیره می‌کند. برای انتقال اطلاعات، از بخش پشتیبان‌گیری فایل JSON دریافت کنید. این نسخه هنوز به پایگاه داده ابری، ورود مدیر یا همگام‌سازی بین دستگاه‌ها متصل نیست؛ برای حسابداری نهایی و داده‌های حساس، اتصال backend امن و احراز هویت لازم است.
